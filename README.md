# Telegram бот для сбора заявок

Бот принимает заявку от администратора, отправляет ее в группу и собирает ответы участников.
После отправки ответа бот пересылает его всем администраторам.

## Возможности
- Команда администратора `/request <тема>` создает новую заявку и отправляет в группу.
- Участники нажимают кнопку "Заполнить заявку" и отправляют ответ одним сообщением.
- Ответы пересылаются администраторам (список ID в переменной окружения `ADMIN_IDS`).
- Команда `/close <id>` закрывает заявку.

## Быстрый старт

1. Создайте `.env` на основе примера.
2. Установите зависимости.
3. Запустите бота.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python bot.py
```

## Настройки

| Переменная | Описание |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен вашего Telegram-бота |
| `ADMIN_IDS` | ID администраторов, через запятую (например: `123,456`) |

## Как использовать

1. Добавьте бота в группу и выдайте права на чтение сообщений.
2. Администратор отправляет `/request молоко`.
3. Участники нажимают кнопку и отправляют ответ.
4. Администраторы получают все ответы в личные сообщения.

## Примечания

- Заявки хранятся в памяти процесса. При перезапуске бота заявки очищаются.
- Для продакшена рекомендуется подключить БД и использовать вебхуки.
